# backguard

Live server for IoT device control


## requirements

- Python 3.10+
- Pip

## installation

```sh
# clone repository
$ git clone https://github.com/yusshu/backguard

# change directory
$ cd backguard

# install dependencies
$ pip install -r requirements.txt 

# copy environment file (and edit it as needed)
$ cp .env.example .env
```

## running

```sh
# start server
$ python -m src.main
```
